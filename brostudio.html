Technical Architecture

Built on Untitled Format: an open-source protocol for permanent, intelligent, sovereign documents.

Core Principles

Every system we build adheres to these foundational principles:

📄 Single-File Architecture

  • Entire document in one HTML file
  • No external dependencies
  • Typically 20-100KB file size
  • Works anywhere, forever

🤖 AI-Ready Structure

  • Semantic HTML5 for machine readability
  • Structured YAML metadata
  • JSON-LD for linked data
  • Extractable, updatable, intelligent

🔒 Digital Sovereignty

  • You own the file completely
  • No cloud dependencies
  • No subscription lock-in
  • Permanent accessibility

⚡ Performance First

  • Loads in milliseconds
  • Works completely offline
  • Minimal bandwidth usage
  • Accessible on any device

♿ Universal Access

  • WCAG 2.1 AA compliant
  • Works on any modern browser
  • Screen reader compatible
  • Responsive across all devices

🔄 Version Control Native

  • Git-friendly by design
  • Full change history tracking
  • Collaborative workflows supported
  • Forkable and remixable

Why Untitled Format?

Untitled Format is an open-source protocol we developed for creating documents that are permanent, intelligent, and sovereign. Unlike proprietary systems that lock your data away, Untitled Format ensures you maintain complete control and ownership. Anyone can use the protocol freely—Brother's Studio builds the premium, best-in-class implementations that showcase what's truly possible.
