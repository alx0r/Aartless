What is SpiderFoot?

SpiderFoot is an open-source intelligence (OSINT) automation tool designed to help investigators, journalists, and security professionals gather information from hundreds of public data sources.

Think of it as your digital detective that automatically queries domains, IP addresses, email addresses, usernames, and more across the internet, then maps the relationships between these entities to reveal hidden connections.

🔍 Journalists

Track digital footprints, verify sources, uncover connections between entities

🕵️ Researchers

Map organizational structures, track threat actors, analyze online presence

🔒 Security Teams

Discover exposed information, identify potential threats, map attack surfaces

⚖️ Investigators

Gather evidence, establish timelines, connect digital identities

Legal & Ethical Notice: Only use SpiderFoot on systems you own or have explicit written permission to investigate. Unauthorized scanning may violate laws and ethical guidelines.

Quick Start

Option A: Docker (Recommended for Beginners)

git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot
docker build -t spiderfoot .
docker run --rm -p 5001:5001 spiderfoot

Then open: http://127.0.0.1:5001 in your browser

Option B: Python (For Developers & Customization)

git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot
pip install -r requirements.txt
python3 sf.py -l 127.0.0.1:5001

Then open: http://127.0.0.1:5001 in your browser

Pro Tip: Docker isolates dependencies and avoids Python version conflicts - perfect for quick setup.

Detailed Installation

Docker Method (All Platforms)

1 Install Docker Desktop

  • Windows/macOS: Download from docker.com
  • Linux: Use your package manager (sudo apt install docker.io)

2 Clone and Build

git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot
docker build -t spiderfoot .

3 Run Container

docker run --rm -p 5001:5001 spiderfoot
Alternative: If the repo has docker-compose.yml, simply run docker compose up

Python Method (macOS/Linux/WSL)

1 Prerequisites

  • Python 3.7+ (3.9+ recommended)
  • pip package manager
  • Git

2 Clone Repository

git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot

3 Install Dependencies

python3 -m pip install -r requirements.txt

4 Launch Server

python3 sf.py -l 127.0.0.1:5001

Windows-Specific Notes

  • Recommended: Use Docker Desktop for Windows
  • Alternative: Install Windows Subsystem for Linux (WSL) and follow Linux instructions
  • Native: Use Python for Windows but expect potential dependency issues

First Run & Investigation Workflow

1 Access the Web UI at http://127.0.0.1:5001

2 Create Your First Scan

  • Click "New Scan"
  • Enter target (domain, IP, email, etc.)
  • Select scan type (start with "Passive Only")
  • Click "Run Scan Now"

3 Review Results

  • View findings in the scan results table
  • Explore relationships in the Graph/Visualization tab
  • Export data as JSON, CSV, or GEXF
Scan Types: "Passive" uses public data sources only. "Active" performs direct reconnaissance that may be detected. Always start with passive scans.

Investigation Tips:

Start Broad

Troubleshooting

Common Issues

Port 5001 already in use

# Use a different port
python3 sf.py -l 127.0.0.1:5002

Python dependency errors

# Try virtual environment
python3 -m venv spiderfoot-env
source spiderfoot-env/bin/activate  # Linux/macOS
# spiderfoot-env\Scripts\activate  # Windows
pip install -r requirements.txt

Docker build fails

  • Ensure Docker Desktop is running
  • Check you're in the correct directory with Dockerfile
  • Try docker system prune to clean cache

Module API keys required

  • Some modules need API keys (Shodan, VirusTotal, etc.)
  • Add keys in Settings → Integrations
  • Many modules work without keys
