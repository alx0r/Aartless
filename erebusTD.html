Executive Summary

The Forever Format™ is a universal, cloneable, open-source protocol for creating living documents that are citable, verifiable, and self-reflexive.

Each document is designed as a single-file intelligence node — lightweight, decentralized, and AI-readable. The system supports academic citation, metadata transparency, and long-term preservation through durable HTML, inline CSS, and structured semantic layers.

Technical Stack

  • Single-file .html architecture with inline CSS and semantic <section> tags
  • Embedded YAML metadata block for citation frameworks (APA, MLA, BibTeX)
  • Embedded JSON-LD schema for machine readability (CreativeWork + ScholarlyArticle)
  • Hash-lock integrity system for provenance verification
  • Optional DID/PGP signatures for authorship verification
  • Offline-first via Service Workers
  • Auto-generated citations & version history

Interoperability Protocols

  • Integration with Anthropic's Model Context Protocol (MCP)
  • Verification alignment with OpenAI's Universal Verifier
  • Cross-document linking via Mnemosyne Graph Taxonomy (MGT)
  • API-ready metadata schema for federated AI collaboration

Verification Clause

All Forever Format documents must include:

  • Verifiable checksum for integrity validation
  • Author disclosure with role transparency
  • Metadata transparency block with creation and modification history
  • Clear marking of AI-generated content under the reflexive section

Accessibility & Compliance

  • WCAG 2.1 / ARIA-ready standard implementation
  • Cross-platform compatibility (mobile, desktop, wearable)
  • Multilingual support framework
  • Progressive enhancement for limited connectivity environments

Ethical Standards

All participants commit to:

  • Transparent co-authorship between humans and AI
  • No commercial exploitation of the protocol without explicit consent
  • Maintaining source integrity, version logs, and accountability for modifications
  • Ethical AI training data sourcing and usage disclosure
