Screenshot Sanitization

Field guide for OSINT-safe image capture & distribution

🔍
EXECUTIVE BRIEF: Screenshots are convenience weapons—they leak OS fingerprints, browser extensions, notifications, location/time metadata, and embedded EXIF. Crop aggressively, use solid redaction (never blur), strip metadata via ExifTool or OS-native tools, and re-capture fullscreen when possible. Assume every pixel is telemetry.

Threat Model: What Screenshots Leak

Surface Metadata (EXIF/XMP/IPTC)

Camera model, GPS coordinates, timestamps, software versions, edit history. Even "stripped" files may retain hidden fields depending on export method.

UI Context Leakage

Visible in frame: OS chrome (taskbar, dock, status bar), browser tabs/bookmarks, window titles, notification center (Wi-Fi network names, carrier, Bluetooth devices), desktop wallpaper, icon arrangement, app versions.

Extension & Tool Fingerprinting

Password managers (1Password, Bitwarden), VPN icons, ad blockers, dev tools—all create unique digital profiles. Browser extensions are OSINT gold for building behavioral dossiers.

Font Rendering & OS Tells

ClearType (Windows), Quartz antialiasing (macOS), Roboto vs San Francisco fonts—rendering styles narrow OS version and sometimes regional settings.

Timing & Correlation Attacks

Screenshot file timestamps + social media post times = correlation vector. Repeated timezone metadata = location fingerprint. Clock in status bar = temporal anchor.

Reflection & Environmental Leaks

Screen reflections in glasses, windows, or glossy surfaces can reveal: faces, room layout, other monitors, physical location. Always check reflective surfaces in frame.

Adversarial Redaction Failure

CRITICAL: Gaussian blur is reversible via deconvolution attacks. Pixelation with low-resolution can be unscrambled. Only solid black boxes (RGB 0,0,0) are forensically safe.

Cloud Sync & Share Sheet Leaks

Auto-upload to iCloud Photos, Google Photos, OneDrive can re-inject metadata or expose to subpoenas. iOS/Android "Share" menus may phone home analytics to OS vendor.

Core Operational Rules

  1. Never share the original file — Always export/convert to a new file after sanitization.
  2. Crop to minimum viable content — Remove status bars, docks, taskbars, browser chrome, tabs, and bookmarks.
  3. Use fullscreen re-capture — Open content fullscreen (no notifications), then screenshot again to remove UI clutter.
  4. Strip metadata forensically — Use ExifTool or OS-native scrubbers. Verify with metadata inspection before sharing.
  5. Solid black redaction only — Never blur. Use opaque black boxes (RGB 0,0,0) for redacting text, faces, or sensitive regions.
  6. Disable auto-sync before capture — Turn off iCloud Photos, Google Photos, OneDrive sync to prevent metadata re-injection.
  7. Check reflections — Scan for reflections in screen, glasses, windows, shiny objects in frame.
  8. Sanitize clipboard — Pasting into some apps preserves hidden metadata layers. Use plain-text intermediaries or re-export.
  9. Add noise for repeat captures — If taking multiple screenshots of similar content, vary cropping/framing to prevent fingerprinting.
  10. Assume hostile forensics — Every pixel, filename, and timestamp is evidence. Sanitize as if adversary has unlimited compute.

Device-Specific Workflows

Windows

Capture region: Win + Shift + S → select area. Use Snipping Tool to crop immediately.

# Strip metadata (built-in): Right-click file → Properties → Details → Remove Properties and Personal Information → "Create a copy with all possible properties removed"

Quick scrub: Open in Paint → File → Save As PNG (removes some EXIF). Then run ExifTool for forensic-grade strip.

exiftool -all= screenshot.png

macOS

Capture portion: Shift + ⌘ + 4. Fullscreen: Shift + ⌘ + 3.

To clipboard only: Hold Control while capturing (avoids saving original file).

# Strip via Preview: Open → File → Export → uncheck "Include Location/Camera Info" # Strip via sips (batch): sips -d all screenshot.png # Strip via ExifTool: exiftool -all= -overwrite_original screenshot.png

iOS (iPhone/iPad)

Pre-flight: Enable Focus Mode to hide notifications. Open content fullscreen.

Capture: Side Button + Volume Up (or Home + Power on older devices).

Crop tightly: Photos → Edit → Crop. Remove status bar, home indicator.

Strip metadata: Use Metapho or Photo Metadata Remover (App Store). Or share via Signal (it strips EXIF when you choose "Send without metadata").

iCloud Photos may preserve original metadata server-side. For sensitive work, disable iCloud sync before capture.

Android

Capture: Power + Volume Down (varies by manufacturer).

Crop: Gallery → Edit → Crop/Rotate → Export. Some vendors strip EXIF on export; verify with metadata viewer.

Strip metadata: Use Scrambled Exif or Photo Metadata Remover (Play Store).

Tools & Arsenal

ExifTool

Gold standard for forensic metadata inspection & removal (cross-platform CLI).

exiftool -all= -overwrite_original file.png

Built-in Scrubbers

Windows: "Remove Properties" (right-click → Properties). macOS: Preview Export options, sips CLI.

Metapho (iOS)

Mobile EXIF viewer & stripper. Shows hidden metadata, one-tap removal.

Signal Messenger

Strips metadata when sending images (if you choose privacy option). Verify current behavior.

ImageMagick

Batch conversion & metadata strip.

convert input.png -strip output.png

mat2 (Metadata Anonymization Toolkit)

Python-based metadata cleaner for images, PDFs, office docs. Privacy-focused.

Pre-Flight Checklist

Notifications disabled (Focus Mode / Do Not Disturb)
Content opened fullscreen (no browser tabs, taskbar, dock visible)
Cropped to minimal viable region (removed status bar, chrome, window title)
Sensitive regions redacted with solid black boxes (not blur)
Metadata stripped via ExifTool or OS-native tool
Verified with metadata inspector (no EXIF/XMP/IPTC fields)
Checked for reflections (screen, glasses, windows)
Cloud sync disabled (iCloud, Google Photos, OneDrive)
Exported to new file (not sharing original)
Filename sanitized (no personally identifiable info)

Advanced Techniques

Burner Screenshot Workflow (High-Threat Model)

For truly sensitive captures (whistleblowing, investigative journalism, protest documentation):

  1. Use a disposable VM (VirtualBox, QEMU) or Tails OS on USB.
  2. Capture screenshot inside VM with no persistent storage.
  3. Transfer via encrypted channel (GPG, Signal) directly from VM.
  4. Wipe VM snapshot after transfer.

Metadata Injection Defense

After stripping, re-encode with neutral/fake metadata to avoid "suspiciously clean" files:

exiftool -Make="Generic Camera" -Model="Unknown" -GPSLatitude= -GPSLongitude= -DateTimeOriginal="2024:01:01 12:00:00" file.png

Creates plausible deniability—file appears normally processed rather than forensically scrubbed.

Differential Privacy for Repeat Screenshots

If taking multiple screenshots of similar content, add slight variance:

  • Vary crop boundaries by 5-10 pixels
  • Rotate 1-2 degrees and re-crop
  • Apply tiny brightness/contrast adjustments (+/- 5%)

Prevents image fingerprinting via pixel-perfect correlation.

Watermark Detection & Removal

Some corporate environments embed invisible forensic watermarks (steganography) in internal documents.

Countermeasure: Re-photograph screen with phone camera (introduces analog noise), or print and re-scan (destroys digital watermarks). Then strip metadata from resulting image.

Removing watermarks from copyrighted/classified material may violate laws (DMCA, espionage statutes). Use only for legitimate fair use / whistleblowing.

Emergency Purge Hotkey

Create OS-level shortcut to instantly wipe:

  • Screenshot folder
  • Clipboard history
  • Temporary files

Windows: PowerShell script bound to Ctrl + Alt + Shift + Delete

macOS: Automator workflow triggered via Keyboard Maestro or BetterTouchTool

Use Case Scenarios

Sharing Stack Traces / Logs (Developer)

Risk: Logs contain hostnames, IP addresses, API keys, session tokens, file paths.

Protocol: Crop to error lines only. Redact hostnames, IPs, and tokens with black boxes. Use plain-text paste (not screenshot) when possible—better for accessibility and indexing.

Design Mocks / UI Prototypes (Designer)

Risk: Layer names, edit history, client names in window titles, Figma/Sketch file paths.

Protocol: Export as flattened PNG from design tool (removes layer metadata). Open in new window with no chrome. Crop tightly. Strip EXIF. Consider adding visible watermark if sharing externally.

Protest / Field Reporting (Activist/Journalist)

Risk: GPS coordinates, faces, license plates, background landmarks, time-of-day correlation.

Protocol:

  1. Disable location services before capture.
  2. Solid black boxes over all faces, license plates, street signs.
  3. Open fullscreen, re-capture to remove UI.
  4. Strip ALL metadata via ExifTool.
  5. Verify zero EXIF before publishing.
  6. Consider time delay before posting (temporal decorrelation).

Bug Reports / Customer Support (End User)

Risk: Browser extensions reveal security posture, bookmarks leak interests, tabs show other services used.

Protocol: Use browser's "New Window" (not tab). Close all other tabs. Hide bookmarks bar. Capture only the relevant area. Alternatively, use browser DevTools screenshot feature (Ctrl+Shift+P → "Capture screenshot" in Chrome) which excludes chrome by default.

Academic Research / Sensitive Documents

Risk: PDF metadata (author, creation software, edit timestamps), institutional watermarks, document IDs.

Protocol: Open PDF in fullscreen reader mode. Zoom to remove margins. Capture only content area. If document has invisible watermarks, consider analog conversion (print → scan with noise). Strip metadata. For extra paranoia, OCR the screenshot to plaintext and re-format.

Automation & Team Workflows

One-Click Sanitization Script

Create a shell script that runs on new screenshots:

#!/bin/bash # sanitize_screenshot.sh # Watches screenshot folder, auto-strips metadata WATCH_DIR="$HOME/Desktop" OUTPUT_DIR="$HOME/Desktop/sanitized" fswatch -o "$WATCH_DIR" | while read; do for file in "$WATCH_DIR"/*.png; do if [ -f "$file" ]; then exiftool -all= -overwrite_original "$file" mv "$file" "$OUTPUT_DIR/" echo "Sanitized: $(basename "$file")" fi done done

Requires: exiftool, fswatch (macOS/Linux). For Windows, use PowerShell with FileSystemWatcher.

Team Onboarding Checklist

When bringing new team members into OPSEC-conscious workflows:

  1. Install ExifTool and verify with test image
  2. Configure OS to save screenshots to dedicated folder (not Desktop)
  3. Practice checklist on dummy screenshots (check each other's work)
  4. Create shared "sanitization review" channel for peer verification
  5. Document incident response plan if unsanitized screenshot is shared

Incident Response: "Oh Shit, I Shared It Raw"

If you accidentally share an unsanitized screenshot:

  1. Immediate: Delete the message/post if possible (Discord/Slack allow deletion within time window).
  2. Notify: Alert team/recipients that a sanitized version is coming.
  3. Assess: What leaked? (Check original file metadata, visible UI elements.)
  4. Mitigate: If GPS leaked, consider whether location is now compromised. If API keys visible, rotate them.
  5. Document: Log incident for post-mortem. Update checklist to prevent recurrence.

Philosophical Notes: Threat Modeling

Not all screenshots require maximum paranoia. Calibrate effort to actual threat level:
  • Low threat: Sharing memes with friends → basic crop, maybe strip EXIF.
  • Medium threat: Work documentation, open-source contributions → remove chrome, strip metadata, check for internal names.
  • High threat: Investigative journalism, whistleblowing, activism → full protocol + burner devices + analog conversion if needed.
Over-sanitizing low-threat content wastes time. Under-sanitizing high-threat content risks lives.

The Adversarial Mindset

When sanitizing, think like an attacker:

  • "What can I infer from this pixel?" — Font rendering, window shadows, color profiles.
  • "What's in the background?" — Desktop icons, notification center, reflections.
  • "What's missing that should be there?" — Suspiciously clean metadata = red flag.
  • "Can I correlate this with other data?" — Timestamp + post time, recurring typos, stylistic fingerprints.

Final Operational Doctrine

Screenshots are tiny dossiers. Every pixel, every metadata field, every UI element is a data point. In aggregate, they form patterns—behavioral signatures that persist across pseudonyms and platforms.

Operational principles:

  • Crop aggressively. Show only what's necessary.
  • Strip forensically. Verify before sharing.
  • Redact permanently. Black boxes, never blur.
  • Think like an adversary. Assume hostile analysis.
  • Automate where possible. Humans forget; scripts don't.

Make screenshots tell only what you want them to. Everything else is operational leakage.
