Kodi Setup Guide

Create your own customized TV experience free from algorithmic control

Welcome to Your Custom TV Experience

This guide will help you set up Kodi, a powerful media center software that transforms your device into a customizable entertainment hub. With Kodi, you can take back control of your media consumption, free from the algorithms and restrictions of commercial streaming platforms.

Note: This guide focuses on Kodi 19.5 (Matrix) and newer versions. While we provide recommendations, always do your own research to ensure you're making informed choices about the addons and configurations that work best for you.

What You'll Need

  • A device (computer, smartphone, TV box) capable of running Kodi
  • Internet connection
  • Optional but recommended: Real Debrid account for higher quality streams
  • Optional: Trakt account to track your viewing progress

Important: Always ensure you're using content legally and ethically according to your local laws and regulations.

Initial Kodi Setup

Sign Up for Services

Before installing Kodi, consider setting up these services:

Real Debrid (Recommended)

Real Debrid provides access to higher quality streams. It's a paid service but offers much better performance than free alternatives.

Real Debrid Website

Real Debrid payments are not recurring - you'll need to manually renew your subscription. You can start with a 2-week trial for approximately £2.50 to test the service.

Trakt

Trakt helps track your viewing progress across devices. It's free to register.

Trakt Website

Install Kodi

Download and install Kodi from the official website:

Download Kodi

Version Note: We recommend Kodi 19.5 (Matrix) or the current stable release. Third-party addons need to be updated by their creators to work with new Kodi versions, so avoid constantly updating to the latest version as it may break your installed addons.

Configure Kodi Settings

After installing Kodi, change these crucial settings (ensure "Expert" mode is selected in the bottom-left to view all settings):

  • Player > Language > Preferred audio language: English (prevents streams from defaulting to foreign audio)
  • Player > Language > Preferred subtitle language: English (prevents foreign subtitle defaults)
  • Media > General > Show parent items: Off (removes unnecessary back button in navigation)
  • Interface > Regional: Configure to your preference
  • System > Display: Ensure correct resolution is set
  • System > Display > Use Fullscreen Window: On (for decent PCs) or Off (for low-powered devices)
  • System > Addons > Unknown Sources: On (required to install third-party addons)

Installing Addons

Understanding Addon Installation

Kodi addons are hosted in repositories, which you add as sources. Once added, you install the repository ZIP, then install addons from that repository.

We'll first install "The Open Wizard" - a maintenance addon that can fix common installation issues like "failed to install a dependency" errors by clearing Kodi's cache.

Installing The Open Wizard

  1. Go to Settings > File Manager
  2. Click "Add Source"
  3. Where it says "None", paste: https://a4k-openproject.github.io/repository.openwizard/
  4. Give it a name (e.g., "OpenWizard") and click "OK"
  5. If you get a connection error, check the URL is exact (including https and slashes)
  6. Go back to the home screen and select "Add-ons"
  7. Click "Install from ZIP file"
  8. Select the repository you just added
  9. Choose the repository ZIP file and wait for installation
  10. Click "Install from Repository" (not ZIP)
  11. Select the Open Wizard repository > Program Add-ons > Open Wizard > Install

When first opening Open Wizard, you'll see tick boxes for data to keep. Leave them as is and click "Continue" - this is for backup/restore functionality.

Clearing Cache with Open Wizard

If addons fail to install later, clear Kodi's cache:

  • Go to Settings > Add-ons > My Add-ons > Program Add-ons > Open Wizard > Open
  • Navigate to the Maintenance tab
  • Click "Total Clean Up" (clears packages, thumbnails, and cache)

Addon Configuration

Configure Each Video Addon

For each video addon (Fen, Seren, Umbrella, The Crew), access settings via:

Settings > Add-ons > My Add-ons > Video Add-ons > [Addon Name] > Configure

Linking Real Debrid

In each addon's settings (usually under "Providers" or similar):

  1. Find the Real Debrid authorization option
  2. It will provide a code
  3. Visit real-debrid.com/devices
  4. Enter the code when signed into your Real Debrid account

For The Crew, authorize Real Debrid through ResolveURL instead: Settings > System > Add-ons > Manage Dependencies > ResolveURL > Universal Resolvers 2 > Authorize Real Debrid

Linking Trakt

In each addon's settings (usually under "Accounts"):

  1. Find the Trakt authorization option
  2. It will provide a code
  3. Visit trakt.tv/activate
  4. Enter the code when signed into your Trakt account

Source Filtering & Sorting

Configure scraping options in each video addon to optimize your streaming experience:

  • Filter out 4K streams if you're viewing on a 1080p screen
  • Always filter out Dolby Vision (not compatible with Windows due to licensing)
  • Optionally prioritize HDR/Blu-Ray streams
  • Sort sources by file size or internet speed if available
  • Exclude 3D sources
  • Optionally exclude CAM/SCREENER/TELE sources (low quality)

Trakt Global Addon Configuration

For the official Trakt addon (from Kodi repository):

  • Enable "Trakt Scrobbling" for movies and TV shows
  • Enable "Sync Movie/TV Show Playback Progress to Kodi"
  • Optionally enable "Show notification on scrobble"
  • Optionally disable "Rate Movie/TV show after watching" to avoid rating popups

Auto-Scraping Configuration

Fen

  • Playback > Movies > Autoplay = Off
  • Playback > Episodes > Autoplay = Off
  • Playback > Episodes > Auto scrape next episode = On

Seren

  • Playback > Movie Play Style = Source Select
  • Playback > Episode Play Style = Source Select

Auto-scraping prepares the next episode's sources in the background while you're watching, making transitions between episodes smoother.

Seren Provider Packages

For Seren, you need to manually add providers:

  1. Go to Seren Settings > Providers > Manage Provider Packages > Install Package > Web Location
  2. Enter: http://bit.ly/a4kScrapers (replace (DOT) with .)

a4k Subtitles Configuration

Set a4k as your default subtitle source in Kodi settings:

  • Settings > Player > Subtitles > Default TV Show Service = a4k Subtitles
  • Settings > Player > Subtitles > Default Movie Service = a4k Subtitles

GUI & Skin Configuration

Install TMDB and Arctic Horizon 2 Skin

For the best visual experience, install these components in order from the same repository:

Repository URL
  1. TMDB (The Movie Database Helper) - Video addon
  2. Skin Variables - Program addon
  3. Arctic Horizon 2 - Look and feel > Skin

When installing Arctic Horizon 2, it will ask if you want to switch skins. Click "No" - you need to configure TMDB first.

Configure TMDB

Access TMDB settings and configure:

  • General > Language and Country = Your preference
  • General > Get additional details and artwork from TMDB = On
  • Trakt > Authorise Trakt account
  • Trakt > Get watched indicators and episode counts = On
  • Trakt > Get resume points = On
  • Players > Update Players from URL = http://bit.ly/tmdbplayers (replace (DOT) with .)

Configure Players

In TMDB Settings > Players > Configure Players:

  • Enable only players with "source select" in the title
  • Disable the default "UPnP" player and "Youtube" if present
  • For each enabled player, set "is_resolvable" to FALSE
  • Set priority numbers (lower = higher in list): Fen(10), Seren(20), Umbrella(50), The Crew(100)

Optional: API Keys

For enhanced metadata, add these API keys in TMDB settings:

OMDB API MDbList API FanArt API

When asked for reason, state: "For home media streaming center"

Configure Arctic Horizon 2 Skin

Switch to Arctic Horizon 2: Settings > Interface > Skin = Arctic Horizon 2

Arctic Horizon 2 is best navigated with keyboard/remote/controller rather than mouse.

Customize Home Menu

Access settings via the gear icon (top-right dropdown):

  1. Settings > Skin > Configure Skin > Menus > Customize Home menu
  2. Delete the default 4 pages (Movies, TV Shows, Music, Videos)
  3. Create 2 new pages for Movies and TV Shows
  4. Label them appropriately and set icons (film.png and director.png work well)

Add Widgets

For each page, add widgets:

  1. In Customize Home Menu, select your page
  2. Navigate to "Widgets" on the right
  3. Click "Choose Widget"
  4. Follow: Add-ons > Video add-ons > TheMovieDB Helper
  5. Select various lists TMDB provides

For personalized lists, use:

Add-ons > Video add-ons > TheMovieDB Helper > Trakt

Here you'll find "Movies Recommended For You", "In-progress Episodes", etc.

Provider Widgets

For network provider widgets (Netflix, Disney, etc.):

Add-ons > Video Add-ons > TheMovieDB Helper > Movies > Providers

Add-ons > Video Add-ons > TheMovieDB Helper > TV Shows > Providers

These show content from those services but aren't linked to the official services.

Final Customization

Explore the skin's extensive customization options:

  • Widget styles (landscapes, posters, etc.)
  • Text information display
  • Autoscroll settings
  • Season/Episode layouts (access via gear icon when browsing a show)
  • Appearance, color, and text settings

Take time to find what works best for your viewing preferences!
