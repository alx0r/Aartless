Protective Gestures

  • Compartmentalize browsers — one mask per role, one identity per session.
  • Route through layered networks — VPN → Tor → destination.
  • Strip metadata before upload — silence the file's memory with tools like MAT2.
  • Rotate devices and sessions — static habits are signatures.
  • Use temporary systems — Tails OS, bootable USBs for high-risk operations.
  • Verify downloads — checksums, signatures, never trust third-party mirrors.
  • Teach others to browse as ghosts — collective anonymity creates collective immunity.

Connection Rituals

Pre-Connection
Close all applications. Enable VPN. Verify kill switches.
During Session
No personal accounts. JavaScript disabled when possible.
Post-Session
Clear all data. Restart browser. Verify IP change.
Long-term
Rotate identities. Update tools. Audit security practices.

Counter-Measures

  • An anonymous channel is not silence — it is camouflage.
  • Every mask is temporary — rotate often, discard when compromised.
  • Trust the protocol, not the node — verify endpoints independently.
  • To browse unseen is to resist capture — visibility is vulnerability.
