Overview

The Forever Format is a universal, cloneable, generative framework for producing intelligence briefs, investigative reports, academic research, and knowledge syntheses. It represents a paradigm shift in how we create, share, and evolve knowledge documents.

Universal Protocol: Forever Format is not just a template—it's a protocol for thought transmission designed for intelligence officers, academics, and cultural analysts.

🧠 Intelligent

AI-readable with embedded semantic prompts and structured metadata for machine parsing and expansion.

📚 Academic

Built-in citation support for APA, MLA, and BibTeX with proper academic metadata and DOI readiness.

🔍 Transparent

Mandatory reflexive sections for bias disclosure, methodological transparency, and ethical accountability.

⚡ Efficient

Single-file HTML under 100KB, mobile-first, print-optimized, and GitHub-ready for instant forking.

Quick Start Guide

Get started with Forever Format in minutes. Follow these steps to create your first living document.

Clone the Template

Start with the base template or fork an existing Forever Format document:

git clone https://github.com/forever-format/template.git
cd template

Customize Metadata

Edit the YAML frontmatter and JSON-LD metadata in the HTML head section:

<!-- 
title: "Your Document Title"
author: "Your Name"
document_type: "Intelligence Report"
tags: ["your", "tags", "here"]
-->

Write Your Content

Fill in the semantic sections following the Universal Section Taxonomy:

<section id="exec-summary">
  <h2>Executive Summary</h2>
  <!-- Your content here -->
</section>

Publish & Share

Commit to GitHub, deploy to web, or share the standalone HTML file:

git add .
git commit -m "Initial Forever Format document"
git push origin main

Technical Specification

Core Architecture Layers

Layer Function Implementation
L1 – Semantic Core Human & AI readable structure HTML5 with semantic sections
L2 – Adaptive Design Responsive presentation CSS Grid + CSS Variables
L3 – Meta Intelligence Machine-readable metadata YAML + JSON-LD schema
L4 – Cognitive Reflection Transparency & ethics Reflexive commentary sections
L5 – Generative Layer AI co-creation & evolution Optional JavaScript hooks

Universal Section Taxonomy

#exec-summary

High-level overview and key findings

#context

Background and historical framing

#methodology

Process transparency and sources

#findings

Core data, evidence, and synthesis

#analysis

Interpretation and critical evaluation

#timeline

Chronological breakdown (if applicable)

#discussion

Cross-sectional insights and implications

#recommendations

Applied synthesis and actionable guidance

#citations

Formal references (BibTeX-ready)

#appendix

Supplementary material and datasets

#reflexive

Cognitive reflection and bias statement

#meta

Version, license, and document history

Metadata Implementation

Every Forever Format document includes comprehensive metadata in two formats:

YAML Frontmatter (HTML Comments)

<!--
title: "Document Title"
author: "Author Name"
affiliation: "Organization"
forever_format: "1.2.0"
document_type: "Intelligence Report"
license: "CC BY-NC-SA 4.0"
version: "1.0.0"
created: "2024-01-01"
updated: "2024-01-15"
citation_style: "APA 7th"
tags: ["intelligence", "analysis", "geopolitical"]
ai_context_tags: ["synthesis", "critical_analysis"]
bias_note: "Analytical perspective and limitations"
-->

JSON-LD Schema

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "ScholarlyArticle",
  "name": "Document Title",
  "author": {
    "@type": "Person",
    "name": "Author Name"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Organization Name"
  },
  "datePublished": "2024-01-01",
  "license": "https://creativecommons.org/licenses/by-nc-sa/4.0/",
  "version": "1.0.0"
}
</script>
