Overview

Forever Format™ is built on mythologically-aligned development phases, each representing a stage in the evolution from individual documents to collective intelligence infrastructure.

Our roadmap spans two parallel tracks:

  • Core Protocol Development: Document format, linking, verification (2025-2027)
  • Emerging Technology: AR wearables, accessibility, cognitive augmentation (2026-2028)

Philosophy: Each phase is named after a figure from Greek mythology, representing the archetypal function of that development stage. This creates a memorable, meaningful progression that transcends typical version numbering.

Core Protocol Development (2025-2027)

Phase I: Erebus Q4 2025

Erebus: Primordial darkness, the foundation from which all emerges. The void that contains infinite potential.

Archetype: The foundation; original chaos from which order emerges

Technical Focus:

  • Core protocol specification (v1.2.0)
  • Reference implementation and templates
  • Semantic section taxonomy
  • YAML + JSON-LD metadata standards
  • Basic citation system (APA, MLA, BibTeX)
  • GitHub repository and documentation

Deliverables:

  • forever-format-v1.2.0.html base template
  • Official white paper and documentation
  • Example documents (intelligence, research, journalism)
  • Community hub at alimcforever.com
Phase II: Mnemosyne Q1-Q2 2026

Mnemosyne: Goddess of memory, mother of the Muses. She remembers all that was, is, and will be.

Archetype: The rememberer; interconnected knowledge

Technical Focus:

  • Cross-document linking protocol
  • Ontological memory layer
  • Entity graph system (people, events, organizations)
  • Bidirectional reference tracking
  • Citation network visualization
  • Version history and provenance tracking

Deliverables:

  • Inter-document linking specification
  • Entity extraction and tagging tools
  • Knowledge graph visualization
  • Document family trees
Phase III: Prometheus Q3-Q4 2026

Prometheus: Titan who stole fire from the gods to give to humanity. He represents radical knowledge-sharing and collective empowerment.

Archetype: The liberator; federated cognition

Technical Focus:

  • Peer-to-peer document synthesis
  • Collaborative editing protocols
  • Distributed verification network
  • Real-time co-authoring
  • Conflict resolution for multi-author documents
  • Decentralized hosting options

Deliverables:

  • Federated document network
  • Collaborative annotation tools
  • Peer review workflow system
  • Distributed backup protocol
Phase IV: Lethe Q1-Q2 2027

Lethe: River of forgetfulness in the underworld. Represents the ethical necessity of revision, retraction, and controlled forgetting.

Archetype: The revisionist; responsible evolution

Technical Focus:

  • Self-revision engine
  • Ethical retraction protocols
  • Version deprecation with explanation
  • AI-driven error detection
  • Bias correction workflows
  • Historical accountability layers

Deliverables:

  • Retraction and correction framework
  • Automated bias detection tools
  • Transparent editing history
  • Ethical deprecation standards
Phase V: Helios Q3-Q4 2027

Helios: Titan of the sun, who sees all from above. Represents transparency, illumination, and public verification.

Archetype: The illuminator; public intelligence

Technical Focus:

  • Public intelligence network
  • Verified document registry
  • Community-driven fact-checking
  • SHA-256 integrity verification
  • Optional PGP signature system
  • Public API for document discovery

Deliverables:

  • Decentralized verification network
  • Public document archive
  • Trust and reputation system
  • Open verification tools

Alternative Support Methods

Can't contribute financially? There are many ways to support Forever Format:

  • Code Contributions: Submit pull requests, fix bugs, optimize performance
  • Documentation: Write tutorials, translate docs, create video guides
  • Design: Create templates, improve CSS, design accessibility features
  • Testing: Report bugs, test on different devices, accessibility audits
  • Community: Answer questions, moderate discussions, welcome newcomers
  • Research: Publish papers using Forever Format, cite in academic work
  • Advocacy: Share on social media, present at conferences, write blog posts

Transparency Commitment: All funding and expenses are publicly documented. Quarterly financial reports will be published on alimcforever.com showing exactly how community support is used.

How Funds Are Managed

Forever Format operates through a transparent, community-governed model:

  • Open Collective: All financial transactions are publicly visible
  • Community Vote: Major funding decisions require community input
  • Quarterly Reports: Detailed breakdowns of income and expenses
  • No Profit Motive: Surplus funds roll into future development
  • Ethical Sourcing: We decline funding from sources that conflict with our values

Funding & Development Principles

🔓 Independence

Forever Format will never be owned by a single entity, corporation, or institution. The protocol, code, and specifications remain perpetually open-source under CC BY-NC-SA 4.0.

🌍 Accessibility First

A minimum of 25% of all funding is dedicated to accessibility features, ensuring Forever Format serves users of all abilities. Accessibility is not an add-on—it's core infrastructure.

🤝 Community Governance

Major decisions about roadmap priorities, feature development, and funding allocation require community input. Foundational Partners participate in governance but don't control outcomes.

📊 Radical Transparency

Every financial transaction, development decision, and governance vote is publicly documented. We operate in the open because knowledge infrastructure must be accountable.

🛡️ Ethical Boundaries

We decline funding from sources engaged in surveillance capitalism, weapons manufacturing, ecological harm, or authoritarian government support. Our values aren't negotiable.

🔄 Sustainable Development

We prioritize long-term sustainability over rapid growth. Features are released when ready, not when deadlines demand. Quality and thoughtfulness over speed.

🧬 Evolutionary Design

Forever Format evolves through community use, critique, and iteration. We learn from how people actually use the format, not just how we imagine they will.

⚖️ Anti-Enclosure

Knowledge infrastructure should resist commodification. Forever Format can never be paywalled, patented, or enclosed. It belongs to the commons, forever.

Reflexive Statement

On Mythological Naming

The use of Greek mythology for phase naming is intentional but not universal. We acknowledge this represents a Western-centric cultural framework. Future phases may draw from other mythological traditions (African, Indigenous, Asian, etc.) as the community evolves and diversifies. We're open to renaming phases if the community finds better metaphors.

On Funding Models

We recognize that requiring funding for open-source infrastructure creates barriers. Our goal is to become self-sustaining through institutional partnerships while keeping all tools freely available. We commit to never paywalling core functionality.

On Accessibility Commitment

The 25% accessibility funding allocation is a floor, not a ceiling. As resources grow, this percentage may increase. We acknowledge that true accessibility requires more than technical features—it requires ongoing community input from disabled users and accessibility advocates.

On AR & Emerging Tech

The AR/wearables roadmap is speculative and depends on technological maturity, funding, and community interest. If these technologies prove inappropriate or harmful, we will pivot. Technology serves human needs, not vice versa.

On Governance

As Forever Format grows, governance structures will need to formalize. We're committed to developing inclusive, democratic processes but acknowledge we're still figuring this out. We invite critique and suggestions for better governance models.
