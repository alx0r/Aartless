Abstract

Forever Format™ defines a universal protocol for creating living, reflexive, AI-interoperable documents. Each file is a self-contained micro-intelligence: transparent, citable, traceable, and modifiable.

Key features:

  • Citable: Built-in YAML + JSON-LD metadata for academic reference
  • Transparent: Mandatory disclosure of bias, sources, and AI collaboration
  • Durable: Single HTML file, sub-100KB, offline-ready
  • Reflexive: Self-critique section for bias disclosure
  • Cloneable: Git-native; every fork = new interpretation
  • Accessible: WCAG 2.1 AA compliant, semantic HTML5

Core Architecture

Five-Layer System

Layer Function Implementation
L1: Semantic Core Human & machine readable HTML5 semantic tags
L2: Design Engine Responsive styling CSS Grid + Variables
L3: Meta Intelligence Machine metadata YAML + JSON-LD
L4: Reflexive Layer Bias transparency Mandatory reflexive section
L5: Generative Layer AI hooks Optional JavaScript

Design Principles

  1. Minimal code, maximal meaning
  2. Offline-ready, printable
  3. Open standards only
  4. Universally readable
  5. No corporate lock-in
  6. Free to fork and remix
  7. Built to last & adapt forever

Universal Section Taxonomy

Standardized structure for intelligence briefs, research papers, and investigative reports:

Section ID Function Usage
#exec-summary Overview Key findings / Abstract
#context Background Historical frame
#methodology Process Sources, limitations
#findings Core data Results, evidence
#analysis Interpretation Critical deconstruction
#timeline Chronology Event sequence
#discussion Synthesis Implications
#recommendations Action items Policy suggestions
#citations References BibTeX-ready
#appendix Supplementary Data, transcripts
#reflexive Self-critique Mandatory bias disclosure
#meta Provenance Version, license, hash
Note: #reflexive and #meta sections are strongly recommended for transparency.

Quick Start Guide

1. Clone the Repository

git clone https://github.com/foreverformat/erebus
cd erebus
cp forever-format-v1.2.0.html my-document.html

2. Edit Metadata

Update the YAML comment block in the <head>:

<!-- YAML Metadata
---
title: "Your Document Title"
author: "Your Name"
version: "1.0.0"
date: "2025-10-23"
tags: ["intelligence", "research"]
license: "CC BY-NC-SA 4.0"
---
-->

3. Fill Semantic Sections

<section id="findings">
  <h2>Findings</h2>
  <p>Your analysis here...</p>
</section>

4. Add Reflexive Statement

<section id="reflexive">
  <h2>Reflexive Statement</h2>
  <p>Bias disclosure and methodology...</p>
</section>

5. Commit and Publish

git add my-document.html
git commit -m "Initial document"
git push origin main
Pro Tip: Enable GitHub Pages for instant publishing at https://yourusername.github.io/repo/document.html

Reflexive Statement

On Design Philosophy

This protocol exists to decentralize knowledge creation and resist epistemic enclosure. Documents are treated as organisms: evolving, self-aware, and accountable.

On AI Collaboration

This white paper was co-created through human-AI collaboration. The AI model (Claude Sonnet 4.5) provided structural suggestions and technical documentation. The human author provided conceptual direction and ethical framing.

Known AI Biases:

  • Preference for structural efficiency over creative ambiguity
  • Western-centric design patterns
  • Optimization for English language
  • Tendency toward comprehensiveness

On Limitations

This format cannot solve:

  • Misinformation or deliberately deceptive content
  • Access inequality (requires web literacy)
  • Fundamental challenges of knowledge representation
  • Power imbalances in publishing and citation
