The Architecture of Permanence

Untitled Format is built on semantic HTML, embedded metadata, and zero dependencies. Here's how it works:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document Title</title> <script type="application/yaml"> --- document: title: "Document Title" version: "1.0.0" created: "2023-11-05" framework: "Untitled Format v0.9.1" data: # Your structured data goes here items: - name: "Example Item" value: 42 --- </script> <style> /* All CSS embedded here */ :root { --primary: #0a0a0a; } </style> </head> <body> <!-- Semantic HTML structure --> <main> <h1>Document Title</h1> <div data-bind="items"></div> </main> <script> // All JavaScript embedded here document.addEventListener('DOMContentLoaded', function() { // Parse YAML metadata const yamlScript = document.querySelector('script[type="application/yaml"]'); // ... data binding logic }); </script> </body> </html>
