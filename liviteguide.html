🚀30-Second Reminder: How to Edit

  1. Go to github.com and log in
  2. Click your repository name (e.g., "wedding")
  3. Click index.html
  4. Click the pencil icon (✏️) to edit
  5. Find your text with Ctrl+F (Windows) or Cmd+F (Mac)
  6. Make your changes
  7. Scroll down and click "Commit changes"
  8. Wait 1-2 minutes, refresh your website

✏️Common Editing Tasks

Change time Current time (e.g., "5:00 PM") Replace with new time
Update address Venue name Replace address lines
Change date Search "weddingDate" Update in YYYY-MM-DD format
Add FAQ Find <section id="faq"> Copy existing FAQ block, modify text

🆘Emergency: "I Broke Something!"

Undo Your Last Change

  1. Go to your repository
  2. Click "History" or "commits"
  3. Find the change before yours
  4. Click "Revert" or "View"
  5. Copy that old version
  6. Edit index.html and paste

Site Won't Load

  • Wait 2-3 minutes after editing
  • Clear browser cache (Ctrl+Shift+R)
  • Try incognito/private window
  • Check Settings → Pages is enabled
  • Verify file is named "index.html"

📝HTML Quick Rules

✅ DO:

  • Change text between tags
  • Update times, dates, addresses
  • Copy entire blocks to duplicate
  • Save often with clear descriptions

❌ DON'T:

  • Delete tags (< >)
  • Remove quotes from attributes
  • Change class names randomly
  • Delete entire sections without backups
