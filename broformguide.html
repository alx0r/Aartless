📄 One File, Everything

Brotherly Format™ creates self-contained micro-intelligences: transparent, citable, traceable, and modifiable documents in a single HTML file.

// Your entire document in one file <!DOCTYPE html> <html> <head> <!-- YAML Metadata --> <title>Your Living Document</title> <style>/* All styles here */</style> </head> <body> <!-- All content here --> <script>/* All functionality here */</script> </body> </html>

Each document is a complete ecosystem containing:

  • Content (semantic HTML5)
  • Design (responsive CSS)
  • Functionality (vanilla JavaScript)
  • Metadata (YAML + JSON-LD)
  • Reflexive transparency

Technical Architecture

Five-layer system for robust, intelligent documents

L1

Semantic Core

Human & machine readable content using HTML5 semantic tags

<section id="findings"> <h2>Key Findings</h2> <p>Structured data...</p> </section>
L2

Design Engine

Responsive styling with CSS Grid + Variables

:root { --primary: #1a1a2e; --highlight: #e94560; } .grid { display: grid; }
L3

Meta Intelligence

Machine metadata using YAML + JSON-LD

--- title: "Document" author: "Name" version: "1.0.0" license: "CC BY-NC-SA 4.0" ---
L4

Reflexive Layer

Bias transparency and methodology disclosure

<section id="reflexive"> <h2>Self-Critique</h2> <p>Bias disclosure...</p> </section>
L5

Generative Layer

AI hooks and optional JavaScript functionality

function updateDocument() { // AI-powered updates // Real-time data integration }

Quick Start Guide

Create your first Brotherly Format™ document in 5 steps

1

Get a Template

Start with our ready-to-use template or ask AI to create one for you.

// Option 1: Use our template wget https://brotherlyformat.com/template.html // Option 2: Ask AI to create one "Create a Brotherly Format HTML document about [your topic] with semantic sections, YAML metadata, and reflexive statement"
2

Add Your Metadata

Customize the YAML metadata block with your document's information.

<!-- YAML Metadata --> <!-- --- title: "Your Document Title" author: "Your Name" version: "1.0.0" date: "2025-10-23" tags: ["intelligence", "research"] license: "CC BY-NC-SA 4.0" ai_collaboration: "Claude Sonnet 4.5" bias_disclosure: "Western analytical framework" --- -->
3

Structure Your Content

Use semantic HTML5 sections to organize your document logically.

<section id="exec-summary"> <h2>Executive Summary</h2> <p>Key findings...</p> </section> <section id="findings"> <h2>Findings</h2> <p>Core data and evidence...</p> </section> <section id="reflexive"> <h2>Reflexive Statement</h2> <p>Bias disclosure and methodology...</p> </section>
4

View Your Document

Open your HTML file directly in any browser or use a local server.

// Double-click the file, or open my-document.html // Or use a local server python -m http.server 8000 // Then visit http://localhost:8000/my-document.html
5

Deploy & Share

Host your document anywhere - GitHub Pages, Netlify, or any web server.

// On GitHub.com: 1. Create new repository 2. Upload your HTML file as 'index.html' 3. Go to Settings → Pages 4. Select 'main' branch and save 5. Your site is live at: username.github.io/repository // Or use Netlify Drop: 1. Drag and drop your HTML file to netlify.com/drop 2. Get instant, permanent URL

Protocol Specification

Technical details for developers and AI systems

📋 YAML Metadata Specification

Every Brotherly Format document must include a YAML metadata block with these required fields:

Field Type Description Example
title String Document title "Market Analysis Q4 2025"
author String Primary author "Jane Smith"
version String Semantic version "1.2.0"
date String Creation date (ISO 8601) "2025-10-30"
bias_disclosure String Methodology and bias statement "Western analytical framework"

🔗 JSON-LD Structured Data

In addition to YAML, include JSON-LD for machine readability:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "Article", "name": "Brotherly Format Protocol Guide", "author": { "@type": "Person", "name": "Brother's Studio" }, "datePublished": "2025-10-30", "version": "1.2.0", "license": "https://creativecommons.org/licenses/by-nc-sa/4.0/" } </script>
