Executive Summary

Sadie Bosworth Atelier serves daring, unconventional brides who value craftsmanship, creative control, and personal expression. This document proposes Untitled Format™ — a new digital product offering that extends Sadie's brand into the wedding invitation space.

"Just as Sadie's brides own their custom gowns, they deserve to own their wedding story — not rent it from a template service."

The Opportunity: Offer brides living, evolvable wedding invitations that they fully own and control. Built as single HTML files hosted on GitHub, these invitations are free, customizable, updatable, and perfectly aligned with the brand's ethos of independence and artistry.

Revenue Model: Design service fee ($500-$1,500) for custom styling and setup. Brides get lifetime ownership with zero ongoing costs.

The Product: Untitled Format™ Living Invitations

What It Is

A modern wedding invitation system delivered as a single, self-contained HTML file. Brides receive a beautifully designed, fully customized page that they host on their own GitHub account — giving them complete ownership, control, and zero ongoing costs.

Core Features

Living Document

Update venue, schedule, or details in real-time. No reprints, no vendor fees.

Custom Styled

Designed to match wedding aesthetic — minimalist, editorial, romantic, or bold.

Guest Owned

Hosted on bride's GitHub. No subscriptions, no expiration dates.

100% Free Hosting

GitHub Pages is free forever. No hidden costs.

Responsive & Fast

Loads instantly on any device. Accessible, printable, shareable.

No Lock-In

Download the file anytime. Move it anywhere. It's yours.

The Technical Architecture

Built on the Untitled Format™ protocol, each invitation includes:

  • Semantic HTML5: Clean structure for humans and machines
  • Embedded CSS: Custom styling, no external dependencies
  • YAML Metadata: Machine-readable event details
  • Single File: Everything in one HTML file (typically 30-80KB)
  • Offline-Ready: Works without internet connection
Example URL: yourname-wedding.github.io

Implementation & Process

Service Offering

Product Name: Living Invitations by Sadie Bosworth Atelier
Pricing: $750-$1,500 (depending on complexity)
Deliverables: Custom HTML file, GitHub setup, style guide, tutorial

Client Journey

Step 1: Consultation
30-minute session to discuss wedding aesthetic, color palette, typography preferences, and technical requirements.

Step 2: Design Phase
Sadie (or designer) creates custom HTML mockup matching wedding vision. Bride reviews and provides feedback.

Step 3: Setup & Training
GitHub account creation, file upload, domain connection (optional). 1-hour training on making simple updates.

Step 4: Launch
Invitation goes live. Bride has full control. Optional support package available.

Required Resources

  • Designer: 8-12 hours per project (HTML/CSS skills required)
  • Templates: 3-5 base templates to customize from
  • Documentation: Client guides for GitHub and editing
  • Support: Optional post-launch support package

Pilot Program Recommendation

Start with 5 beta clients at discounted rate ($500). Gather testimonials, refine process, then scale to full offering at $1,200 average.
